# Agentic 101 MCP workshop registration

Register with the GitHub account you will use for the workshop:

**[Register for the workshop](https://github.com/langd0n-labs/agentic-101-mcp-registration/issues/new?template=register.yml)**

Submitting the registration issue enrolls that GitHub account in the active
Classroom50 classroom. GitHub will send an organization invitation if the
account is not already a member. Accept that invitation before opening the
workshop assignment.
